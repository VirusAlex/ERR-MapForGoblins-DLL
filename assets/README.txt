Map For Goblins - DLL Edition v%VERSION%
For ERR. Unofficial, not affiliated with the ERR team.
~9100 map icons. No regulation.bin changes.
Pure DLL - no gfx or other extra files.

INSTALL:
Copy MapForGoblins.dll and MapForGoblins.ini into your ERR
  dll\offline\  folder.
Launch through ERR as usual.

UPDATING from an older version:
Just replace MapForGoblins.dll in dll\offline\ with this one. Your
MapForGoblins.ini is kept (new options are added automatically).
This version no longer uses a gfx file - icons are injected by the DLL.
If you installed an older version, DELETE the now-unused
  addons\MapForGoblins\  folder (it held the old 02_120_worldmap.gfx).

SETTINGS:
All icon categories are ON by default. Edit dll\offline\MapForGoblins.ini
to turn off the ones you don't want.
In-game mod menu: press F10 (or Y+R3 on a controller) to open a
settings panel and toggle icon categories. Category toggles take effect
right away on the open map; some options apply on the next map open.
