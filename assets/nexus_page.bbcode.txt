[size=4][b]Description[/b][/size]
[color=#D4D4D8]DLL version[/color] of the Map for Goblins mod. Thousands of loot and world icons on the in-game map, and [b]no regulation.bin changes[/b]: all map data gets injected into memory at runtime, so it won't conflict with other mods that edit the regulation.

There are four builds on the Files tab, pick the one for your game:
[list]
[*][b]ERR version[/b], for [url=https://www.nexusmods.com/eldenring/mods/541]ERR[/url]. ~9000 icons, including the ERR-specific stuff (Rune Pieces, Ember Pieces, Kindling Spirits, unique loot etc).[/*]
[*][b]Vanilla version[/b], for the base game + Shadow of the Erdtree. ~6700 icons, same mod, just without the ERR-only categories. Also works with the [url=https://www.nexusmods.com/eldenring/mods/428]Item & Enemy Randomizer[/url] - see below.[/*]
[*][b]Convergence version[/b], for [url=https://www.nexusmods.com/eldenring/mods/3419]The Convergence[/url]. ~7200 icons generated from the overhaul's own data, so it covers its relocated loot, new bosses and reworked zones. Matches the Convergence version it was built against (currently 2.2.3A) - after a Convergence update expect some markers to be off until this build is updated too.[/*]
[*][b]ERTE version[/b], for [url=https://www.nexusmods.com/eldenring/mods/2747]ERTE[/url]. ~7600 icons generated from the overhaul's own data. Matches the ERTE version it was built against - after an ERTE update expect some markers to be off until this build is updated too.[/*]
[/list]
Based on [url=https://www.nexusmods.com/eldenring/mods/3091]Map for Goblins[/url] by Harmonixer and [url=https://github.com/Gacsam/Goblin-ERR]Goblin-ERR[/url] by Gacsam, rebuilt from scratch as a single DLL + gfx for icons.

[size=5][color=#ff8c00][b]Most icon categories are OFF by default - turn them on![/b][/color][/size]
After installing, open [b]MapForGoblins.ini[/b] and set the categories you want to [b]= true[/b] (show_bosses, show_graces, show_smithing_stones, ...). Or just drop in the included [b]"all-on" preset[/b] - it replaces the default ini and switches everything on at once. [b]You can also enable categories in-game: press [color=#ff8c00]F10[/color] (or [color=#ff8c00]Y+R3[/color] on a controller) to open the new config overlay.[/b] [b]Seeing no icons? You almost certainly haven't enabled any in the ini - it is not broken.[/b]

[size=4][b]Main features[/b][/size]
[list]
[*][b]In-game config overlay[/b] (new): press [b]F10[/b] (or [b]Y+R3[/b] on a controller) to open a settings panel right in the game - toggle any icon category on/off, flip the master switch, and copy a marker dump, without alt-tabbing to edit the ini. Mouse, keyboard and controller all work. Changes apply live; re-open the world map to see them.[/*]
[*]Icon categories that can be turned on/off individually in [b]MapForGoblins.ini[/b]: weapons, armour, talismans, spells, key items, smithing stones, gloveworts, cookbooks, bell bearings, gathering nodes, bosses, graces, stakes of Marika, spirit springs, imp statues, paintings, summoning pools, map fragments, gestures, NPC invaders, puzzles etc.[/*]
[*]Icons in a region only show up after you've found that region's map fragment (can be disabled).[/*]
[*]Things you've already collected disappear from the map: including gathered material nodes (like Arteria Leaf), Rune/Ember Pieces etc. Defeated bosses either hide or get a checkmark (configurable).[/*]
[*]Every marker shows its location name, down to sub-areas (like Siofra Aqueduct/Siofra River etc). The mod uses original game strings, everything should be localised out of the box.[/*]
[*]The INI maintains itself. If there's no file - it gets created. If there are new options after an update - they will be added automatically.[/*]
[*]Master on/off for all icons: the "Show map icons" switch in the overlay, or [b]F10[/b] / [b]Y+R3[/b] directly when the overlay is turned off in the ini.[/*]
[*][b]Item & Enemy Randomizer support[/b] (vanilla build, on by default): loot markers read the loaded regulation at startup, so each one shows the item that's [i]actually[/i] there - right name, right icon - and disappears when you pick up the real light point. Works with any seed, no per-seed setup. Turn it off in the ini if you play vanilla without the randomizer.[/*]
[*][b]Spoiler-free mode[/b] (optional, set anonymous_loot in the ini): every loot marker shows a plain "?" icon and a generic label instead of the real item, so you can find loot without knowing what it is - made for blind / randomizer runs.[/*]
[*]The ERR version can optionally tie ERR's own pre-placed markers (camps, merchants, bosses, dungeon entrances) to the same display rules as this mod's icons, so everything on the map follows one logic: show after map discovery, hide once cleared. If you prefer ERR's markers as they are, turn these options off in the ini.[/*]
[/list]

[size=4][b]Installation - Vanilla version[/b][/size]
You need a mod loader, either [b]ModEngine3 (me3)[/b] or [b]ModEngine2[/b].

[b]Option A: ModEngine3 (me3), recommended[/b]
[spoiler]
[list=1]
[*]Install me3 ([url=https://github.com/garyttierney/me3/releases]me3_installer.exe[/url], docs at [url=https://me3.help/]me3.help[/url])[/*]
[*]Copy the [b]MapForGoblins[/b] folder from the archive next to your .me3 profile (e.g. eldenring-default.me3)[/*]
[*]Open the .me3 profile in Notepad and make sure it has:
[code]profileVersion = "v1"

[[supports]]
game = "eldenring"

[[packages]]
path = 'MapForGoblins'

[[natives]]
path = 'MapForGoblins/MapForGoblins.dll'[/code]
[/*]
[*]Double-click the .me3 file to play[/*]
[/list]
[/spoiler]
[b]Option B: ModEngine2[/b] [i](see the 2nd image on this page for a visual setup guide)[/i]
[spoiler]
[list=1]
[*]Get [url=https://github.com/soulsmods/ModEngine2/releases]ModEngine2[/url] and extract it anywhere (NOT into the game folder)[/*]
[*]Copy the [b]MapForGoblins[/b] folder into the ModEngine2 directory (next to launchmod_eldenring.bat)[/*]
[*]In [b]config_eldenring.toml[/b] add the DLL and the asset folder:
[code]external_dlls = [ "MapForGoblins\\MapForGoblins.dll" ]

mods = [
    { enabled = true, name = "MapForGoblins", path = "MapForGoblins" },
    { enabled = true, name = "default", path = "mod" }
][/code]
[/*]
[*]Run launchmod_eldenring.bat[/*]
[/list]
[color=#ff8c00][b]Mind the slashes:[/b][/color] keep the paths with double backslashes (\\) or forward slashes (/) - a single backslash is a TOML escape, which makes the whole config invalid and stops [i]every[/i] mod from loading.
[/spoiler]
[b]Option C: [url=https://www.nexusmods.com/eldenring/mods/5998]Mod Engine 2 with Lazy Loader[/url][/b] [i](popular on Steam Deck)[/i]
[spoiler]
Same as ModEngine2, but its config lives in the [b]base/[/b] folder.
[list=1]
[*]Copy the [b]MapForGoblins[/b] folder into the main [b]Game[/b] folder (next to eldenring.exe, mod, mods - [b]not[/b] inside base/)[/*]
[*]Open [b]base/config.toml[/b] and add the DLL to external_dlls and the asset folder to mods (MapForGoblins listed FIRST so its world-map file wins):
[code]external_dlls = [
    "MapForGoblins/MapForGoblins.dll"
]

mods = [
    { enabled = true, name = "MapForGoblins", path = "MapForGoblins" },
    { enabled = true, name = "default", path = "mod" }
][/code]
[/*]
[*]Launch from eldenring.exe as usual[/*]
[/list]
[color=#ff8c00][b]Mind the slashes:[/b][/color] in this config a single backslash is an escape character, so a path like "MapForGoblins\MapForGoblins.dll" makes the WHOLE config.toml invalid and stops [i]every[/i] mod from loading - not just this one. Use forward slashes like above, or double every backslash (\\). The DLL must be in [b]external_dlls[/b]: Lazy Loader only loads ModEngine from base/, it does not auto-inject mod DLLs.
[/spoiler]
Settings are in [b]MapForGoblins/MapForGoblins.ini[/b] [b]Reminder: most categories are OFF by default - enable the ones you want here, or use the included all-on preset.[/b]

[size=4][b]Using it with the Item & Enemy Randomizer[/b][/size]
Use the [b]Vanilla version[/b]. Install it the same way (ModEngine3/me3 or ModEngine2), alongside the randomizer's generated [b]regulation.bin[/b] in your load order. Nothing else to set up: the live-loot options are [b]on by default[/b] in the vanilla build, so at startup the markers read your loaded seed and show the real item (name + icon) and hide on the actual light-point pickup. For a blind run, set [b]anonymous_loot = true[/b] in the ini to replace every loot marker with a "?" and a generic label.

[size=4][b]Installation - Convergence version[/b][/size]
[spoiler]
[list=1]
[*]Download the Convergence file and unpack it[/*]
[*]Copy the [b]MapForGoblins[/b] folder into your ConvergenceER folder (next to Start_Convergence.bat)[/*]
[*]In [b]config_eldenring.toml[/b] add the DLL to external_dlls and the asset folder ABOVE the "mod" entry (in ModEngine2 the FIRST entry is highest priority - our world-map file already contains the Convergence map UI):
[code]external_dlls = [
    ...existing entries...,
    "MapForGoblins\\MapForGoblins.dll",
]

mods = [
    { enabled = true, name = "MapForGoblins", path = "MapForGoblins" },
    { enabled = true, name = "mod", path = "mod" }
][/code]
[/*]
[*]Launch through Start_Convergence.bat as usual[/*]
[/list]
[color=#ff8c00][b]Mind the slashes:[/b][/color] keep the paths with double backslashes (\\) or forward slashes (/) - a single backslash is a TOML escape, which makes the whole config invalid and stops [i]every[/i] mod from loading.
Settings are in [b]MapForGoblins/MapForGoblins.ini[/b]. Note: the Convergence Launcher may rewrite config_eldenring.toml when it updates the mod - re-check the two edits after updates. [b]Reminder: most categories are OFF by default - enable the ones you want here, or use the included all-on preset.[/b]
[/spoiler]

[size=4][b]Installation - ERTE version[/b][/size]
[spoiler]
ERTE runs on [b]Mod Engine 3 (me3)[/b] through its .me3 profile (e.g. eldenring-ERTE-SOTE-CoopReady.me3).
[list=1]
[*]Download the ERTE file and unpack it[/*]
[*]Copy the [b]MapForGoblins[/b] folder next to ERTE's mod folder, i.e. into [b]...\me3\config\profiles\eldenring-mods\[/b] (alongside the "ERTE SOTE" folder)[/*]
[*]Open the ERTE [b].me3[/b] profile in Notepad and add the DLL as a native and the asset folder as a package (listed ABOVE the ERTE package):
[code][[natives]]
path = 'eldenring-mods\MapForGoblins\MapForGoblins.dll'

[[packages]]
path = 'eldenring-mods\MapForGoblins'

[[packages]]
path = 'eldenring-mods\ERTE SOTE'[/code]
(ERTE has no world-map UI of its own, so there's no conflict - this just makes sure our world-map file loads.)[/*]
[*]Launch through the ERTE .me3 profile as usual[/*]
[/list]
Settings are in [b]MapForGoblins/MapForGoblins.ini[/b]. [b]Reminder: most categories are OFF by default - enable the ones you want here, or use the included all-on preset.[/b]
[/spoiler]

[*]Vanilla version: [url=https://github.com/garyttierney/me3/releases]ModEngine3[/url] or [url=https://github.com/soulsmods/ModEngine2/releases]ModEngine2[/url][/*]

[/list]
