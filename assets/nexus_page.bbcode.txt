[size=4][b]Description[/b][/size]
[color=#D4D4D8]DLL version[/color] of the Map for Goblins mod. Thousands of loot and world icons on the in-game map, and [b]no regulation.bin changes[/b]: all map data gets injected into memory at runtime, so it won't conflict with other mods that edit the regulation.

There are eight builds on the Files tab, pick the one for your game:
[list]
[*][b]ERR version[/b], for [url=https://www.nexusmods.com/eldenring/mods/541]ERR[/url]. ~9000 icons, including the ERR-specific stuff (Rune Pieces, Ember Pieces, Kindling Spirits, unique loot etc).[/*]
[*][b]Vanilla version[/b], for the base game + Shadow of the Erdtree. ~6700 icons, same mod, just without the ERR-only categories. Also works with the [url=https://www.nexusmods.com/eldenring/mods/428]Item & Enemy Randomizer[/url] - see below.[/*]
[*][b]Convergence 2.x version[/b], for [url=https://www.nexusmods.com/eldenring/mods/3419]The Convergence[/url] 2.x (runs on ModEngine2). ~7200 icons generated from the overhaul's own data, so it covers its relocated loot, new bosses and reworked zones. Matches the Convergence version it was built against (currently 2.2.3.1) - after a Convergence update expect some markers to be off until this build is updated too.[/*]
[*][b]Convergence 3.x version[/b], for [url=https://www.nexusmods.com/eldenring/mods/3419]The Convergence[/url] 3.x (runs on ModEngine3 / me3). Same ~7200 icons generated from the overhaul's own data; this is a separate file because 3.x moved to ModEngine3, so it installs differently (see below). Pick this one if your Convergence is 3.x.[/*]
[*][b]ERTE version[/b], for [url=https://www.nexusmods.com/eldenring/mods/2747]ERTE[/url]. ~7600 icons generated from the overhaul's own data. Matches the ERTE version it was built against - after an ERTE update expect some markers to be off until this build is updated too.[/*]
[*][b]Golden Age version[/b], for the Elden Ring Golden Age overhaul. ~6700 icons generated from the overhaul's own data. Matches the Golden Age version it was built against - after an update expect some markers to be off until this build is updated too.[/*]
[*][b]ELDEN VINS version[/b], for the ELDEN VINS overhaul. ~7100 icons generated from the overhaul's own data. Matches the version it was built against - after an update expect some markers to be off until this build is updated too.[/*]
[*][b]Elden Ring Reborn version[/b], for the Elden Ring Reborn overhaul. ~6900 icons generated from the overhaul's own data. Matches the version it was built against - after an update expect some markers to be off until this build is updated too.[/*]
[/list]
Based on [url=https://www.nexusmods.com/eldenring/mods/3091]Map for Goblins[/url] by Harmonixer and [url=https://github.com/Gacsam/Goblin-ERR]Goblin-ERR[/url] by Gacsam, rebuilt from scratch as a [b]single DLL[/b] - the icons are injected into the map at runtime, so the mod ships no gfx and modifies no game files.

[size=5][color=#ff8c00][b]Install is just one DLL[/b][/color][/size]
This is a pure DLL: the only files are [b]MapForGoblins.dll[/b] and [b]MapForGoblins.ini[/b] (kept together). All icon categories are [b]ON by default[/b] - open the ini, or press [b][color=#ff8c00]F10[/color][/b] (or [b][color=#ff8c00]Y+R3[/color][/b] on a controller) in-game, to turn off any you don't want.
[b]Updating from an older version?[/b] This version no longer uses a gfx file. After replacing the DLL, [color=#ff8c00]delete the old 02_120_worldmap.gfx[/color] (the old "menu" folder, and for ERR the "addons\MapForGoblins" folder) and remove any old "mods"/"packages" entry that pointed at the MapForGoblins asset folder - only the DLL needs to be registered now.

[size=5][color=#ff8c00][b]In-game mod menu[/b][/color][/size]
[img]https://staticdelivery.nexusmods.com/mods/4333/images/10062/10062-1781886515-155689242.png[/img]
Press [b][color=#ff8c00]F10[/color][/b] (keyboard) or [b][color=#ff8c00]Y+R3[/color][/b] (controller) to open a settings panel right inside the game - no more alt-tabbing to edit the ini. From it you can:
[list]
[*]Turn any icon category on or off, or use [b]Show all[/b] / [b]Hide all[/b] at once[/*]
[*]Flip the master "Show map icons" switch[/*]
[*]Copy a marker dump for bug reports[/*]
[/list]
[b]Toggling a category takes effect right away on the open map[/b] - its icons appear or disappear without closing the map. (Some other options, such as spoiler-free mode, apply the next time you open the map.) Mouse, keyboard and controller supported.

[size=4][b]Main features[/b][/size]
[list]
[*][b]In-game mod menu[/b] (see above): F10 (or Y+R3 on a controller) opens a settings panel to toggle icon categories, the master switch and Show all / Hide all without editing the ini. Category toggles take effect right away on the open map.[/*]
[*]Icon categories that can be turned on/off individually in [b]MapForGoblins.ini[/b]: weapons, armour, talismans, spells, key items, smithing stones, gloveworts, cookbooks, bell bearings, gathering nodes, bosses, graces, stakes of Marika, spirit springs, imp statues, paintings, summoning pools, map fragments, gestures, NPC invaders, puzzles etc.[/*]
[*]Icons in a region only show up after you've found that region's map fragment (can be disabled).[/*]
[*]Things you've already collected disappear from the map: including gathered material nodes (like Arteria Leaf), Rune/Ember Pieces etc. Defeated bosses either hide or get a checkmark (configurable).[/*]
[*]Every marker shows its location name, down to sub-areas (like Siofra Aqueduct/Siofra River etc). The mod uses original game strings, everything should be localised out of the box.[/*]
[*]The INI maintains itself. If there's no file - it gets created. If there are new options after an update - they will be added automatically.[/*]
[*]Master on/off for all icons: the "Show map icons" switch in the overlay, or [b]F10[/b] / [b]Y+R3[/b] directly when the overlay is turned off in the ini.[/*]
[*][b]Item & Enemy Randomizer support[/b] (vanilla build, on by default): loot markers read the loaded regulation at startup, so each one shows the item that's [i]actually[/i] there - right name, right icon - and disappears when you pick up the real light point. Works with any seed, no per-seed setup. Turn it off in the ini if you play vanilla without the randomizer.[/*]
[*][b]Spoiler-free mode[/b] (optional, set anonymous_loot in the ini): every loot marker shows a plain "?" icon and a generic label instead of the real item, so you can find loot without knowing what it is - made for blind / randomizer runs.[/*]
[*]The ERR version can optionally tie ERR's own pre-placed markers (camps, merchants, bosses, dungeon entrances) to the same display rules as this mod's icons, so everything on the map follows one logic: show after map discovery, hide once cleared. If you prefer ERR's markers as they are, turn these options off in the ini.[/*]
[/list]

[size=4][b]Installation - Vanilla version[/b][/size]
You need a mod loader, either [b]ModEngine3 (me3)[/b] or [b]ModEngine2[/b].

[b]Option A: ModEngine3 (me3), recommended[/b]
[spoiler]
[list=1]
[*]Install me3 ([url=https://github.com/garyttierney/me3/releases]me3_installer.exe[/url], docs at [url=https://me3.help/]me3.help[/url])[/*]
[*]Copy [b]MapForGoblins.dll[/b] and [b]MapForGoblins.ini[/b] next to your .me3 profile (e.g. eldenring-default.me3)[/*]
[*]Open the .me3 profile in Notepad and make sure it has:
[code]profileVersion = "v1"

[[supports]]
game = "eldenring"

[[natives]]
path = 'MapForGoblins.dll'[/code]
[/*]
[*]Double-click the .me3 file to play[/*]
[/list]
[/spoiler]
[b]Option B: ModEngine2[/b]
[spoiler]
[list=1]
[*]Get [url=https://github.com/soulsmods/ModEngine2/releases]ModEngine2[/url] and extract it anywhere (NOT into the game folder)[/*]
[*]Copy [b]MapForGoblins.dll[/b] and [b]MapForGoblins.ini[/b] into the ModEngine2 directory (next to launchmod_eldenring.bat)[/*]
[*]In [b]config_eldenring.toml[/b], under [modengine], register the DLL:
[code]external_dlls = [ "MapForGoblins.dll" ][/code]
[/*]
[*]Run launchmod_eldenring.bat[/*]
[/list]
[/spoiler]
[b]Option C: [url=https://www.nexusmods.com/eldenring/mods/5998]Mod Engine 2 with Lazy Loader[/url][/b] [i](popular on Steam Deck)[/i]
[spoiler]
Same as ModEngine2, but its config lives in the [b]base/[/b] folder.
[list=1]
[*]Copy [b]MapForGoblins.dll[/b] and [b]MapForGoblins.ini[/b] into the main [b]Game[/b] folder (next to eldenring.exe)[/*]
[*]Open [b]base/config.toml[/b] and add the DLL to external_dlls:
[code]external_dlls = [
    "MapForGoblins.dll"
][/code]
[/*]
[*]Launch from eldenring.exe as usual[/*]
[/list]
The DLL must be in [b]external_dlls[/b]: Lazy Loader only loads ModEngine from base/, it does not auto-inject mod DLLs.[/spoiler]
Settings are in [b]MapForGoblins.ini[/b] - all categories are ON by default, turn off what you don't want (or use F10 in-game).

[size=4][b]Using it with the Item & Enemy Randomizer[/b][/size]
Use the [b]Vanilla version[/b]. Install it the same way (ModEngine3/me3 or ModEngine2), alongside the randomizer's generated [b]regulation.bin[/b] in your load order. Nothing else to set up: the live-loot options are [b]on by default[/b] in the vanilla build, so at startup the markers read your loaded seed and show the real item (name + icon) and hide on the actual light-point pickup. For a blind run, set [b]anonymous_loot = true[/b] in the ini to replace every loot marker with a "?" and a generic label.
